# ROBOFEST 2026 

A modern, responsive landing page for
ROBOFEST for ROBOTiX Club, NIT Raipur.

##  Live Website: https://robofest-landing-kj1t.vercel.app

##  Technologies Used:

- React.js – Building reusable UI components
- Vite – Fast development server and build tool
- JavaScript – Website functionality and interactivity
- HTML – Structuring the webpage
- CSS – Styling, layouts, and responsive design
- Framer Motion – Smooth animations and transitions
- Lucide React – Modern icons for the interface
- Git & GitHub – Version control and source code hosting
- GitHub Pages / Vercel – Website deployment
  
##  Theme
A futuristic robotics-inspired design
focused on innovation and technology.
